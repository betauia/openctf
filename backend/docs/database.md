# Changing SQL

Queries live in `internal/database/queries` and the schema is defined by the goose migrations in `internal/database/migrations`.
The Go code in `internal/database/dbgen` is generated by [sqlc](https://sqlc.dev) from both. Don't edit it by hand.

1. Install sqlc:

   ```sh
   go install github.com/sqlc-dev/sqlc/cmd/sqlc@v1.31.1
   ```

2. (only when required) Add a new migration (`internal/database/migrations/0000N_description.sql`).
3. Edit or add queries in `internal/database/queries/*.sql`. Each query needs a `-- name: QueryName :one|:many|:exec|:execrows` comment.
4. Regenerate from the `backend` directory:

   ```sh
   sqlc generate
   ```

5. Commit the generated files together with the SQL change.

Nullable columns become pointers and `uuid` columns use the standard library `uuid` package (see [`sqlc.yaml`](sqlc.yaml)). Use `sqlc.narg('name')` for optional parameters, e.g. `COALESCE(sqlc.narg('name'), name)` for a partial update.
