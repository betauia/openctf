### Installation

#### Docker
1. Clone the repo
  ```sh
  git clone https://github.com/betauia/openctf.git
  ```
2. Copy and modify .env
  ```sh
  cp .env.example .env
  ```
3. Run docker compose
  ```sh
  docker compose -up
  ```

#### Kubernetes
Will be supported in the future.
